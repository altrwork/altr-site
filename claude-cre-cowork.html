Claude in CRE: Cowork

Jarred RobidouxAugust 12, 20262 min read

Most CRE teams using Claude for underwriting are still uploading a file, downloading the result, and reopening it in Excel. Cowork removes those handoffs.

The difference

Claude in a browser answers questions about uploaded files. Claude Cowork can work directly in an approved project folder on your computer.

Browser chat versus desktop work

If your process is upload, prompt, download, open, revise, and upload again, Claude is helping—but your team is still carrying the work between systems.

The most important difference with Claude Desktop is access to local files. Cowork operates inside a project or folder you choose, which means it can create and edit the actual files your team uses without the browser download loop.

Set up a Cowork project

Install Claude Desktop, open Cowork, and create a project for the workflow. The project folder becomes the workspace: source documents, templates, spreadsheets, and final deliverables stay together on the computer.

Keep the scope deliberate. Give Cowork access to the folder it needs, not the entire machine, and use a clear project structure so both the team and Claude understand which files are inputs, working drafts, and outputs.

An underwriting example

A common CRE workflow begins with an offering memorandum and ends with a pro forma model. In browser chat, the team uploads the OM, asks Claude to build a model, downloads the spreadsheet, and opens it in Excel.

With Cowork, the OM and template already live in the project. Claude can read the source, build the underwriting model, save it in the correct folder, and continue making changes to that same file. The model exists on the computer throughout the process.

From chatbot to teammate

Cowork lets Claude sit down and work directly in your files: no downloading, no re-uploading, and no bouncing between a browser tab and Excel.

Put Cowork together with Skills and connectors and the operating model changes. Skills carry the repeatable method. Connectors reach CRM and property systems. Cowork produces and edits the deliverables where the team already works.

The next step is routines—work Claude can run while you are away.

Working idea

The real upgrade is not a better answer. It is a model that can continue working on the same approved files your team will actually use.
