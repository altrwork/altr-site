How altr built a remote MCP server to connect Claude to a startup incubator's operations

spARK Labs by ARK Invest, the nonprofit innovation hub in St. Petersburg, runs on four tools: BossHub for intake forms, Verkada for building access, Nexudus for memberships and room bookings, and Outlook for email. None was connected to Claude, so every onboarding meant reading a form in one system and retyping it into three others. altr built a single remote MCP server on Cloudflare Workers that connects all four to Claude and Claude Cowork behind one endpoint.

There are no separate integrations and no API keys to distribute. Team members sign in with their existing Microsoft accounts through Microsoft OAuth, and an email allowlist limits the tools to authorized operators. Nothing installs locally and there is no per-user setup.

BossHub: Reading form responses

Read access to the inquiry forms the team uses to track new member interest, member engagement and event ideas. Claude lists forms, pulls recent submissions or looks up an inquiry by name or email. A member activation starts here: Claude reads the plan requested, the company details and what the member needs before moving in.

Verkada: Provisioning building access

Claude searches for a Verkada user by email, creates a new access user, lists access groups and adds the user to the right group for building entry. These operations write to the building access system, so they sit behind the email allowlist and a dry run flag for testing without live changes.

Nexudus: Managing memberships and bookings

Nexudus tracks members, plans and room reservations. Onboarding tools look up a coworker and create a member with the right plan; day-to-day tools list resources and create or cancel room bookings. Plans map by tariff ID, so a new member record has the correct access level from the start.

Outlook: Drafting emails

The Outlook tool creates drafts through the Microsoft Graph API. Claude composes and addresses the message and leaves it in the configured sender's mailbox. It does not send.

Together, these tools take a new member from form submission to membership record, building access and a drafted welcome email in one conversation. New team members connect in minutes with their Microsoft account.

Also with this client: automating the work behind expenses and events and AIR Supply founder-advisor matching. Background on the pattern: MCP server design for internal AI tools.
