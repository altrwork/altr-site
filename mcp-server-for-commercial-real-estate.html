An MCP server puts property records inside the assistant your brokers already use.

Commercial real estate runs on lookups: who owns this, what did it trade for, what is the debt, what are the comps. An MCP server is how an AI assistant runs those lookups against the record instead of answering from memory.

Short answer

An MCP server for commercial real estate is a small service that lets an AI assistant such as Claude query parcels, owners, sales, recorded debt and your own CRM through named tools, with sign-in and permissions. The assistant answers from the record it just read, so a broker gets the owner, the sale history and the comparables instead of a plausible guess.

What does an MCP server do for a CRE team?

It turns the lookups a broker or analyst repeats all day into tools the assistant can call. Instead of opening the county appraiser site, searching a parcel, copying figures into a spreadsheet and doing it again for every comparable, the person asks one question and the assistant runs the lookups.

A useful CRE server usually exposes a short list of tools:

  • Find a parcel from an address, and return the owner of record, the use code, the building area and the assessed value.
  • Resolve an LLC owner to the people behind it through the state corporate registry, and list everything else that entity owns.
  • Pull comparable sales with the screens a careful analyst would apply, and say what was excluded and why.
  • Show recorded debt where the county publishes it, and say plainly where it does not.
  • Read and write the firm's own contacts, deals and documents, so research becomes a record rather than a chat transcript.

The Model Context Protocol is the open standard that makes those tools usable from any compatible assistant. Anthropic created it and in December 2025 donated it to the Agentic AI Foundation, part of the Linux Foundation, so no single vendor controls it. What an MCP server is covers the protocol itself.

What data can sit behind it?

Three kinds, and the licence decides which. Public record is free to use and is where most of the value for owner research sits. Your own CRM and files are yours. Licensed data belongs behind the server only when the licence allows AI access.

What goes wrong when one is built carelessly?

The failures are quiet. The assistant still answers, fluently, and the answer is wrong. These are the ones we have seen in our own build and designed against:

  • Matching a house number as a substring, so a search for 715 returns 1715 on the same street.
  • Treating a nominal $100 deed as a sale, or dividing a portfolio price across one building's square feet.
  • Reading the last few weeks of sales as a market slowdown, when it is the lag between a closing and its recording.
  • Returning an empty debt list for a county that publishes no mortgage index, which reads as a building with no debt.
  • Letting a layer that is down fail the whole request instead of falling back to the stored record and saying so.

Each of these is a design rule, not a model problem. The server has to say what it does not know, date what it does, and refuse inputs that would fabricate a result.

Should you build one or use a vendor's?

Use a vendor's server for data you already license from that vendor, if they publish one. Build one for public record in your own market and for your own CRM, because nobody else will model your counties or your pipeline the way you work them.

The build is ordinary software engineering: a hosted service, sign-in so the server knows who is asking, read tools separated from write tools, rate limits, and tests that pin the cases that went wrong once. We build ours on Cloudflare Workers; the architecture is written up here.

How does a team add one to Claude or ChatGPT?

As a remote connector, once, by an administrator. As of September 2026:

  • Claude. On Team and Enterprise plans, an owner adds the server's URL under Organization settings, Connectors. Each person then connects and signs in with their own account. On Pro and Max plans, individuals add it themselves under Connectors.
  • ChatGPT. Custom MCP servers are added as apps through developer mode, which a Business or Enterprise admin may have to turn on for the workspace first.

Before it goes to the whole team, give it to one broker for a week and read what it returned. Check three things: that each answer names its source and file date, that an address with a unit number returns the right parcel, and that a county with no mortgage index says so instead of reporting no debt.

What does one look like in practice?

Our own is the Tampa property records connector: Hillsborough, Pinellas, Pasco and Polk county records inside the chat window, with ownership resolved to people, recorded debt where it exists, screened comparables, and a branded valuation summary at the end. The same records power mortr, our CRM for commercial real estate teams, so the chat and the CRM read and write one store.

Working rule

If a broker on your team is copying an answer out of a public system by hand, that lookup is a tool waiting to be written. Start with the one they repeat most, and make it say what it could not find.

Common questions

What is an MCP server for commercial real estate?

It is a small service that exposes property data and your firm's own records to an AI assistant as named tools, such as finding a parcel by address, listing an owner's other buildings, or pulling comparable sales. The assistant calls the tool and answers from the result instead of from memory.

Which AI assistants can use a CRE MCP server?

Any client that supports the Model Context Protocol, which includes Claude, ChatGPT, Microsoft Copilot, Gemini and developer tools such as Cursor and VS Code. A remote server with sign-in is added once by an administrator and then used by everyone on the team under their own login.

Can an MCP server connect to CoStar?

Not legitimately. CoStar has no official connector and its terms restrict sharing logins with AI agents and exposing licensed data to generative AI. Public record, your CRM and data you license for that use are what belong behind a CRE MCP server.

What public data can a CRE MCP server use in Florida?

County property appraiser rolls and sales files, the Florida Department of Revenue assessment files, the Sunbiz corporate registry, clerk recording indexes where the county publishes one, SEC filings for securitized loans, and federal SBA 504 loan data.

How long does it take to build one?

It depends on how many sources and write actions it needs. A read-only server over one clean source is a small build. Several counties, entity resolution, debt records and write access to a CRM is real software engineering, scoped in writing before it starts.
