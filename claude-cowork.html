Claude Cowork is Claude doing the task, not just answering about it, and it is becoming part of every conversation.

In a normal chat you carry every file and every step between Claude and your other tools. In Cowork you describe the outcome, and Claude plans the steps, works in the folders and systems you connect, and hands back the finished file.

Short answer

Claude Cowork is Claude carrying out a multi-step task for you: working in folders you connect, using your connectors, and returning a finished document or spreadsheet. It launched as a separate mode. On September 16, 2026, Anthropic began merging it into ordinary Claude chat, starting with Pro and Max, so any conversation can hand Claude a task. Team, Free and Enterprise follow.

What happened to Claude Cowork?

It is being folded into Claude itself. On September 16, 2026, Anthropic announced that Claude Cowork and chat are becoming one Claude: you ask for what you need in one message box, and Claude decides whether that is a quick answer or a longer task.

  • Pro and Max get the merged experience first, rolling out over several weeks across web, desktop and mobile. If your message box no longer offers a choice between Chat and Cowork, you have it.
  • Team and Free follow after that.
  • Enterprise admins get 30 days' notice before the change reaches their organization.

Nothing is lost in the move. Anthropic says existing chats, projects, artifacts, connectors and Skills stay where they were. Until the change reaches your plan, the Cowork selector is still in the bottom left of the message box, and everything below applies to both versions. The capability is the same. What goes away is the separate door.

How is Cowork different from a normal Claude chat?

In chat, you do the handoffs. In Cowork, Claude does them. Anthropic describes Cowork as bringing Claude Code's agentic abilities to general knowledge work. After the merge, the right-hand column is simply what Claude does when a request needs it.

Where does Cowork run, and what can it reach?

As of September 2026, Cowork runs in Claude Desktop for macOS and Windows, on the web and on mobile. What it can touch is decided by what you connect, and that has not changed with the merge.

  • Cloud sessions. Anthropic's help center says Cowork can run tasks in the cloud, in an isolated environment on Anthropic's servers, with sessions saved to your account so you can pick them up on another device. This is still labelled beta.
  • Your computer. Claude can only read and write in folders you have connected. A cloud session reaches those folders only while the Claude Desktop app is open on that computer and the session was started on desktop. The same applies to your browser and computer use.
  • Connectors. Cowork uses the same connectors as chat, including Google Workspace, Microsoft 365, GitHub and custom MCP servers your organization adds. Local MCP servers work only from the desktop app.
  • Scheduled tasks. Tasks set with /schedule run in the cloud, so your laptop does not need to be awake.
  • Plugins and Skills. A plugin bundles Skills, connectors and sub-agents. A Skill tells Cowork how your team does a task, so it does it the same way each time.

You also choose how often it stops to ask. Manual mode asks before each action, auto mode approves actions it judges safe after a safety check, and Claude asks for explicit permission before permanently deleting any file.

How should a team start using Cowork?

Start with one recurring deliverable, one folder and one person who owns the result. "Everyone try Cowork" produces a week of demos and no change in how work gets done.

  1. Pick a deliverable with a known shape: a weekly report, a first-pass contract review, a model built from the same inputs each month.
  2. Make a folder for it with the inputs you own. Connect that folder, not your whole drive, and do not put in licensed data you are not allowed to share.
  3. Write the procedure down as folder instructions or a Skill: the steps, the checks and what "done" looks like.
  4. Connect the live systems it needs, and leave write-capable tools on approval until you trust the pattern.
  5. Run it, review the file, fix the instructions, and run it again. After three clean runs, consider scheduling it.

On Team and Enterprise plans, Owners control Cowork in Organization settings. Anthropic's help center lists toggles for Cowork itself, cloud sessions (on by default for Team, off for Enterprise), the built-in browser, auto-approve mode and "Always allow" for connector tools, which is off by default so write tools ask each time. Rolling it out to a whole team is covered in how to roll out Claude to a team.

Where does Cowork go wrong?

  • Usage runs faster. Every step spends tokens, so a long task uses more of your plan's allowance than a chat. Keep tasks focused and start a new session for unrelated work.
  • Too much access. A connected home folder or an always-approved write tool turns a small mistake into a large one.
  • Instructions hidden in content. A web page or document Cowork reads can contain text aimed at the model. Keep approval on for anything that sends, pays or deletes.
  • Nobody reviews. A finished-looking file is not a checked file. The person who owns the deliverable signs off on it.

What does Cowork look like in commercial real estate?

An analyst who underwrites in chat still bounces a spreadsheet through download and re-upload. In Cowork, the same request builds the model in the deal folder and keeps editing it there, and the next person on the deal opens the file without reconstructing the conversation.

We walk through that setup, including an office-condo underwriting request against local files, in Claude in CRE: Cowork, part of a four-part field guide with Skills, Connectors and Scheduled Tasks.

Working rule

Give Cowork one deliverable, the narrowest folder and connectors it needs, and a written definition of done. Widen its access only after it has earned it.

Common questions

Is Claude Cowork being discontinued?

Not the capability, only the separate mode. From September 16, 2026, Anthropic is merging Cowork into ordinary Claude conversations, starting with Pro and Max plans, then Team and Free, with Enterprise admins given 30 days' notice. Existing projects, connectors and Skills carry over, and Claude decides per request whether to answer or run a task.

Is Claude Cowork free?

No. As of September 2026, Cowork is included with paid Claude plans: Pro, Max, Team and Enterprise. It is available in Claude Desktop on macOS and Windows on all of them, and on the web and mobile for Pro, Max and Team, and for Enterprise where an admin turns it on.

Does my computer need to stay on for Cowork to work?

Only when the task needs something on that computer, such as a local folder or your browser, in which case Claude Desktop must be open and connected. Cloud sessions and scheduled tasks run on Anthropic's servers, so they keep going while your laptop is closed.

Can Cowork delete or change my files?

It can read and write only in folders you have connected, and Anthropic says it asks for explicit permission before permanently deleting any file. Edits inside a connected folder are real edits, so connect a working folder rather than the only copy of something important.

What is the difference between Claude Cowork and Claude Code?

They share the same agent approach. Claude Code is built for software work in a terminal, an editor or the desktop app. Cowork applies it to general knowledge work such as documents, spreadsheets, research and file organization, for people who do not write code.

Can Cowork use our internal business systems?

Yes, through connectors. Cowork uses the connectors your organization has enabled, including custom remote MCP servers that an Owner adds on Team and Enterprise plans. If a system has no connector, Cowork cannot reach it, and that is usually the case for building one.
