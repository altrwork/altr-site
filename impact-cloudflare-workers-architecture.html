Why we deploy our MCP servers on Cloudflare Workers.

Every connector we build for a client is an MCP server. It is the thing that lets Claude reach their records and answer a real question about their buildings, their orders or their contracts instead of guessing. We have built a handful now, and they all go to the same place: Cloudflare Workers. Here is why.

Start with the obvious constraint. There are two of us. Engineering hours are the scarcest thing we have and none of them can go on babysitting servers. A connector used to mean a box to run it on, a deploy pipeline, monitoring, and somebody to notice when it fell over at the weekend. On Workers it is one command. We run wrangler deploy and it is live on a URL in seconds, in a few hundred cities, with nothing to patch and nobody on call.

The rest of what a connector needs is already in the same account. Need a database? That is a D1 binding, a few lines in the config file. Need it to run every night? Add a cron line. Need it on its own domain? Point one, same dashboard. We have never had to leave Cloudflare to finish a connector, and we have never spent an evening getting two vendors' credentials to agree with each other.

The part clients actually feel is connecting to the thing. They paste a URL into Claude, click connect, and sign in through a browser. There is no API key to generate and no token to paste into a config file, so nothing sensitive ends up in a text file on somebody's laptop. And because the connection knows who signed in, the assistant can write as well as read. It can log the deal, create the contact and produce the document, all as that person.

One more thing we did not expect to like as much as we do: a single deployment can serve several teams at once. Our servers hold nothing between requests, so the same server hands out a different set of tools depending on which route you connect to. Valuation gets valuation tools, capital markets gets recorded debt, property management gets its own. Adding a team is a line in a table and another deploy. All of it sits on the $5 Workers plan with ten million requests a month included, which is more than any of our clients has come close to using. That is the whole reason we can quote a connector in days.
